# Even room lighting

The owner rejected the centered two-light design and requested evenly distributed, visually balanced lighting. Source fix `5f40c3e60` replaces the radius-limited circular room fill with one opaque union of the room interior, composited once. The fill includes the raised north wall so wall-to-floor lighting does not have a horizontal cutoff. The existing interior receiver and exterior mask still protect the shell and window glass. Fixtures now cover both room axes and supply local highlights at 22% gain; the room no longer depends on those spots for basic visibility. LOW/MEDIUM/HIGH retain the same distribution while changing exposure.

Live real-canvas proof: `node dev/room-lighting-even-proof.mjs after` checks nine sizes, from 5x5 through 60x12 and 12x60, plus L-shaped, U-shaped, and overlapping-rectangle rooms. Rectangular floor illumination max/min is 1.08–1.12, L/U is 1.13, and overlap is 1.23. Before the fix, the 9x7 room measured 3.18 and a 12x60 room measured 4.70. The isolated diffuse fill has zero variation across the tested irregular-room floors, so rectangle overlaps do not multiply its brightness. Exterior chamfers are excluded using the actual interior receiver mask, not a hand-drawn inset.

Furnished metal-floor station and saved wood-floor reference rendered and were visually inspected. Live Build view opened without degraded render layers; closing it preserved station data. The LOW/MEDIUM/HIGH proof passed again with mean lightmap transmission .644/.690/.734, unchanged fixture geometry across presets, .06 glow, keyboard activation and reload persistence. Startup checks initially failed while the preview server was unavailable; it was restarted with `node dev/seed.js --keep`, and the live checks passed afterward. The actual user save was not edited. Evidence is under `.worldshots/even-lighting/`: before/after JSON, furnished/build/wood-room PNGs, `three-levels.log`, and `furnished.json`.

Focused regressions passed: simulation-lighting (39), room-lighting-settings, and stationbake.chunk (64, including chunk/monolithic parity). The standard `npm run test:fast` wrapper reached its 900000ms limit without a reported test failure. The complete suite was rerun with `node scripts/timeout.mjs --label even-lighting-validation --timeout=1800000 -- npm run test:fast:raw` and passed all 723 steps, exit 0 (`test-fast-extended.log`).
